正確使用流程
ChatGPT (GPT-4o)
1. 下載 Layout PNG
2. 複製 Prompt
3. 在 GPT-4o 對話框上傳：Layout PNG ＋ 所有商品原圖（必須一起上傳）
4. 貼上 Prompt 送出
Gemini (Imagen 3)
1. 下載 Layout PNG
2. 複製 Prompt
3. 在 Gemini 上傳：Layout PNG ＋ 所有商品原圖
4. 貼上 Prompt 送出
⚠ 商品原圖必須附上，AI 才能精確比對商品外觀。只貼 Prompt 不上傳圖片，AI 會自行生成相似但不正確的商品。
